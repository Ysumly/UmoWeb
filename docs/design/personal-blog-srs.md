# 个人博客系统 — 软件需求规格 (SRS)

> 版本: 1.0 | 日期: 2026-06-26 | 状态: 已确认

---

## 1. 项目概述

### 1.1 项目定位

个人作品展示型博客（Portfolio Blog），非论坛、非社区、不支持用户注册。

### 1.2 核心目标

- 展示文章、技术能力与 UI 设计能力
- 提供公开访问端 + 私人管理后台
- 优良的扩展性，未来可加入在线编辑器、小游戏、小说发布、读后感等模块

### 1.3 范围边界

| 包含 | 不包含 |
|---|---|
| 公开文章浏览 | 用户注册 / 登录 |
| 文章分类与标签 | 评论系统 |
| Markdown 内容编辑与管理 | 搜索引擎收录 |
| 管理员单用户 JWT 认证 | 多人协作 / 多用户 |
| 本地图片上传 | 第三方评论 / 社交分享 |
| 响应式设计（桌面+移动端） | SSR / SSG |
| 在线 Markdown 编辑器（本地化） | — |

---

## 2. 用户角色

| 角色 | 标识方式 | 权限范围 |
|---|---|---|
| **游客** | 无需认证 | 浏览首页、分类浏览文章、搜索文章、文章详情、About/Project 页面、使用在线 Markdown 编辑器 |
| **管理员** | 秘密 URL 路径 + JWT 账号密码登录 | 以上全部 + 文章 CRUD、草稿管理、分类/标签管理、图片上传 |

---

## 3. 功能性需求

### 3.1 公开端

| 编号 | 功能 | 描述 |
|---|---|---|
| F-PUB-01 | 首页 | 展示博客标题、导航入口，视觉效果留坑（后续设计确定） |
| F-PUB-02 | 分类浏览（图书馆模式） | 用户按分类层级浏览，展开分类后显示该分类下的文章卡片列表。分类内可进一步按标签过滤 |
| F-PUB-03 | 搜索页 | 独立搜索页面，用户输入关键字搜索文章标题/正文。不含关键字时列出全部文章。搜索频率限制：同一 IP 10 秒内仅允许 1 次请求 |
| F-PUB-04 | 文章详情 | Markdown 渲染阅读，显示标题、正文、分类、标签、发布时间 |
| F-PUB-05 | About 页面 | 个人介绍，静态内容或从后端可配置 |
| F-PUB-06 | Project 页面 | 项目展示，静态内容或从后端可配置 |

### 3.2 管理端

| 编号 | 功能 | 描述 |
|---|---|---|
| F-ADM-01 | 管理员登录 | 通过秘密路径访问登录页，输入账号密码，后端签发 JWT（24h 过期） |
| F-ADM-02 | 文章列表（管理） | 展示所有文章（含草稿），支持状态筛选 |
| F-ADM-03 | 新建文章 | Markdown 编辑器，填写标题、正文、分类、标签，可存草稿或发布 |
| F-ADM-04 | 编辑文章 | 修改已有文章的各项内容 |
| F-ADM-05 | 删除文章 | 软删除或硬删除 |
| F-ADM-06 | 草稿管理 | 草稿与已发布分状态管理，草稿仅在管理端可见 |
| F-ADM-07 | 分类管理 | 新建/编辑/删除分类，支持层级（parent_id）。规则：笔记按学科扁平分类，小说按书籍→章节两级分类，读后感按书籍扁平分类 |
| F-ADM-08 | 标签管理 | 新建/编辑/删除标签 |
| F-ADM-09 | 图片上传 | 支持拖入图片到编辑器、Ctrl+V 粘贴截图，自动上传并插入光标位置。校验格式（jpg/png/gif/webp），不限制文件大小。粘贴/拖入自动触发上传 |

### 3.3 内容扩展

| 编号 | 功能 | 描述 |
|---|---|---|
| F-EXT-01 | 文本类多类型支持 | `contents` 表的 `type` 字段仅用于文本内容模块（NOTE / NOVEL / BOOK_REVIEW），通过 `metadata` JSON 存储各类型专属字段。非文本模块（游戏、编辑器等）独立建表，不参与 `contents.type` |

### 3.4 在线 Markdown 编辑器

| 编号 | 功能 | 描述 |
|---|---|---|
| F-EDT-01 | 编辑页 | 桌面端左右分栏（编辑+预览），手机端编辑/预览切换模式，响应式适配 |
| F-EDT-02 | 导入文件 | 支持拖入或打开本地 `.md` 文件到编辑器 |
| F-EDT-03 | 导出保存 | 编辑内容下载为 `.md` 文件保存到本地电脑 |
| F-EDT-04 | 预览渲染 | 实时渲染，支持代码高亮、表格、图片等标准 Markdown 语法 |
| F-EDT-05 | 权限 | 公开可用，无需登录（纯浏览器端运行，不涉及后端存储，不提供图片上传） |

## 4. 非功能性需求

| 编号 | 类别 | 描述 |
|---|---|---|
| NF-01 | 安全-访问控制 | 管理端通过秘密路径 + JWT 双重防护，JWT 过期时间 24h |
| NF-02 | 安全-搜索引擎 | `robots.txt` + `<meta name="robots" content="noindex">` 全局禁爬 |
| NF-03 | 安全-频率限制 | 搜索接口同 IP 10 秒内最多 1 次请求 |
| NF-04 | 缓存策略 | 前端静态资源使用内容哈希命名 + `immutable` 长缓存，`index.html` 设置 `no-cache` |
| NF-05 | 扩展性 | 文本类内容统一表 + JSON metadata 扩展；独立模块（游戏等）独立建表 |
| NF-06 | 响应式 | 全站响应式设计，适配桌面端和移动端 |
| NF-07 | 密码安全 | 管理员密码 bcrypt 加密存储 |
| NF-08 | 图片上传 | 仅管理端可上传，文件存本地磁盘按年/月分目录，不限大小，格式限 jpg/png/gif/webp |
| NF-09 | 数据持久 | 全部内容、分类、标签数据存储在 MySQL |

## 5. 约束与假设

### 5.1 技术约束

| 项目 | 约束 |
|---|---|
| 后端框架 | Spring Boot 4.1.0 |
| Java 版本 | 17 |
| ORM | MyBatis 4.0.1 |
| 数据库 | MySQL |
| 前端框架 | Vue（版本待实施阶段确定） |
| 认证 | JJWT 0.12.6 |
| 构建工具 | Maven |

### 5.2 架构约束

| 项目 | 约束 |
|---|---|
| 前后端关系 | 前后端分离，Vue 独立项目，Spring Boot 纯 API |
| 存储 | 内容数据 MySQL，图片本地磁盘 |
| 部署 | 初期可无 Nginx，后续可选加反向代理 |

### 5.3 已知不做的事

| 不做 | 原因 |
|---|---|
| 用户注册 / 登录 | 非社区，仅单管理员 |
| 评论系统 | 极简展示 |
| SEO / SSR | 不希望被搜索到 |
| 图片自动清理 | 简化运维 |
| 多用户 / RBAC | 单管理员足够 |
