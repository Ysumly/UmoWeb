# UmoWeb 软件规格与当前实现

> 基线日期: 2026-09-10
> 状态: 公开端和核心 API 已实现，管理端业务页待实现
> 事实来源: 当前源代码

---

## 1. 项目定位

UmoWeb 是个人作品和内容展示型博客，不是社区、论坛或多人内容平台。

核心目标：

- 公开浏览 Markdown 内容。
- 提供分类、标签、搜索和页面配置。
- 提供单管理员管理后台。
- 支持笔记、小说章节、读后感三类文本内容。
- 支持本地图片上传。

明确不包含：

- 用户注册和公开登录。
- 评论、点赞、关注。
- 多管理员和 RBAC。
- SSR、SSG 和搜索收录优化。
- 图片自动清理。

---

## 2. 用户角色

| 角色 | 权限 |
|---|---|
| 游客 | 浏览已发布内容、分类、标签、About、Project |
| 管理员 | 登录，并管理文章、分类、标签、图片、站点配置 |

管理端不是基于角色的权限系统，只有单一管理员身份。

---

## 3. 功能规格与状态

### 3.1 公开端

| 功能 | 代码状态 | 与文档相关的事实 |
|---|---|---|
| 站点信息 | 后端和公开前端已实现 | 返回标题、副标题、About/Project Markdown |
| 分类树 | 后端和公开前端已实现 | 支持按 `type` 过滤 |
| 标签列表 | 后端和公开前端已实现 | 返回全部标签 |
| 已发布文章列表 | 后端和公开前端已实现 | 只返回 `PUBLISHED` |
| 文章详情 | 后端和公开前端已实现 | 从磁盘读取 Markdown，并返回前后文章 |
| 搜索 | 后端和公开前端已实现 | 仅匹配标题和摘要，10 秒限流 |
| About/Project | 后端和公开前端已实现 | 从 `site_options` 读取 Markdown |
| 在线 Markdown 编辑器 | 未实现 | 目标为纯浏览器本地编辑 |

### 3.2 管理端

| 功能 | 代码状态 | 与文档相关的事实 |
|---|---|---|
| 管理员登录 | 后端和前端已实现 | JWT 默认 24 小时 |
| 修改密码 | 后端已实现，前端未实现 | 新密码至少 6 位 |
| 文章列表 | 后端已实现，前端未实现 | 可查看草稿 |
| 新建/编辑文章 | 后端已实现，前端未实现 | 同步写 Markdown 和数据库 |
| 删除文章 | 后端已实现，前端未实现 | 删除文件、关联和记录 |
| 分类 CRUD | 后端已实现，前端未实现 | 删除保护、父级存在性和循环校验已实现 |
| 标签 CRUD | 后端已实现，前端未实现 | 有关联内容时返回 409 |
| 图片上传 | 后端已实现，前端未实现 | 支持 jpg/png/gif/webp，最大 50MB |
| 站点设置 | 后端已实现，前端未实现 | KV 更新使用 upsert |

### 3.3 内容模型

文本内容类型：

- `NOTE`：笔记。
- `NOVEL`：小说章节。
- `BOOK_REVIEW`：读后感。

状态：

- `DRAFT`：仅管理端可见。
- `PUBLISHED`：公开端可见。

`metadata` 在数据库中为 JSON 字符串，查询后转换为对象返回。

## 4. 非功能要求

| 类别 | 当前实现 |
|---|---|
| 认证 | JWT + `Authorization: Bearer` |
| 密码 | BCrypt |
| 搜索限流 | 同 IP 10 秒 1 次，内存实现 |
| 文件大小 | Multipart 单文件和请求均 50MB |
| 图片类型 | MIME 白名单 |
| 存储 | MySQL + 本地文件系统 |
| 响应式 | 公开端已完成桌面和 390px 检查；管理端业务页待开发 |
| 爬虫控制 | `index.html` 有 `noindex`，无 `robots.txt` |
| 错误格式 | `{ code, message }` |
| 前端缓存 | 尚无部署级缓存配置 |

## 5. 技术约束

| 项目 | 实际值 |
|---|---|
| 后端 | Spring Boot 4.1.0 |
| Java | 17 |
| ORM | MyBatis 4.0.1 |
| 数据库 | MySQL |
| JWT | JJWT 0.12.6 |
| 前端 | Vue 3.5 + Vite 8 + Vue Router 5 + Pinia 3 |
| 构建 | Maven + npm |

前后端分离部署。开发环境由 Vite 代理 `/api` 和 `/images` 到后端。

## 6. 已知缺口

1. 分类和标签删除保护错误。
2. 搜索不覆盖 Markdown 正文。
3. 分类筛选不包含子分类。
4. 文件系统与数据库事务不具原子性。
5. 小说书级目录解析过于简化。
6. 公开端已接入真实 API；在线编辑器和管理端业务页仍为占位。
7. 没有可重复执行的完整数据库集成测试、前端组件测试和浏览器 E2E。

以上缺陷不代表期望行为，完整记录见 [audit-log.md](../project/audit-log.md)。
