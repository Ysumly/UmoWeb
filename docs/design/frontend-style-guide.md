# UmoWeb 前端视觉与交互规范

> 基线日期: 2026-09-11
> 适用范围: 当前公开端与管理端文章工作流
> 事实来源: `Client Side/umo-web-frontend/src/style.css` 与公开端组件

## 1. 视觉方向

公开端采用“当代古籍纸本”方向：使用纸本底色、墨色正文、朱红印记、青黛辅助色和少量金色分隔。它借鉴纸本与书籍气质，但版式仍保持现代 Web 的清晰层级和响应式网格。

避免把页面做成单色复古仿制品：

- 纸色只承担背景与纸张空间，正文必须保持高对比墨色。
- 朱红用于操作、分类和印记，青黛用于标签与次级状态，金色用于编号和小标题。
- 不使用圆角卡片堆叠、玻璃拟态或大面积渐变装饰。

## 2. 颜色 Tokens

| Token | 亮色 | 暗色 | 用途 |
|---|---|---|---|
| `--paper` | `#eee3c9` | `#171d19` | 页面背景 |
| `--paper-deep` | `#e3d2b2` | `#202821` | 书封、页脚和分隔层级 |
| `--surface` | `#f8f1df` | `#222a24` | 卡片与表单表面 |
| `--ink` | `#3d2b1c` | `#e9dfca` | 正文与主要标题 |
| `--muted` | `#78644d` | `#b3a58e` | 摘要和辅助文字 |
| `--accent` | `#a63532` | `#cd554d` | 主操作、编号和印记 |
| `--secondary` | `#496449` | `#8cab91` | 标签与辅助状态 |
| `--gold` | `#b58936` | `#ce9f4f` | eyebrow、边框和强调 |

主题值使用 `light | dark`，写入 `<html data-theme>`；用户选择保存到 `localStorage` 的 `umo-theme`。首次访问跟随系统偏好，页面初始化时同步设置以避免闪烁。

## 3. 排版

- 展示标题：`Songti SC / STSong / Noto Serif SC / SimSun / Georgia`。
- 界面文字：`Noto Sans SC / Microsoft YaHei / ui-sans-serif`。
- 正文行高保持 `1.9–1.95`，技术文章正文宽度控制在约 `760px`。
- 英文 eyebrow 使用大写、增加字距；中文标题不需要人为拉开每个字，除非是书籍封面等展示场景。
- 正文页不使用持续运动元素；代码块允许横向滚动，但页面本身不得横向溢出。

## 4. 组件规则

- 页面宽度上限 `1180px`，移动端左右留白至少 `14px`。
- 内容卡片使用 `1px` 边框和纸张阴影，只有主推卡片使用 `2px` 边框和更大留白。
- 圆角限制在 `4–8px`；书籍与印章可以保留直角或双线边框。
- 按钮只使用朱红实心、描边、文本和安静四种层级，不混用其他按钮体系。
- 标签使用青黛描边；筛选激活态可以反转为青黛底色。
- 表格、筛选、分页和移动导航必须保留清楚的键盘焦点。

## 5. 动效等级

### 电影化

用于首页首次进入：

1. 主题色幕布退场。
2. 纸面轻扫。
3. 标题分行翻起。
4. 书封和阴影落位。
5. 内容错峰进入。
6. 朱红印记落章。

暗色纸面扫光使用约 `2.5%` 暖金亮度，不使用亮白扫光。

### 聚焦

用于书库、详情、About 和 404：

- 路由过渡控制在 `260–480ms`。
- 路由切换使用水平方向：前进时新页面从右侧进入，旧页面向左退出；返回时方向相反。
- 内容使用一次性淡入和位移，不持续晃动。
- 正文不使用滚动视差。

### 后台

管理端沿用同一色彩与字体 tokens，使用 `120–180ms` 的短过渡。桌面端为常驻侧栏，移动端为顶部菜单和抽屉导航；文章、About 和 Project 编辑在桌面端使用编辑/预览并排，窄屏切换单栏。

所有装饰动画必须在 `prefers-reduced-motion: reduce` 下关闭，移动端不使用鼠标视差。

## 6. 当前边界

- 首页、书库、搜索、文章详情、About、Project 和 404 已接入真实 API。
- 管理端文章、分类、标签、站点设置和修改密码已接入真实 API，并实现响应式布局、表单状态、错误反馈和未保存保护。
- 公开在线编辑器仍是占位页。
- 公开端错误态不回退静态 fixtures；搜索 429 使用倒计时反馈。
- `marked` 渲染禁用原始 HTML；代码高亮按需加载 Java、JavaScript、SQL 和 Bash。
