# 问题 004：文章管理中的状态顺序应从草稿开始

- 记录时间：2026-09-21
- 来源：用户日常使用反馈
- 页面/区域：管理端文章管理
- 状态：已修复（2026-09-24）

## 用户原文

> 在文章管理中, 草稿应该在文章的最上面, 具体顺序为
>
> 草稿
>
> 待发布
>
> 已发布
>
> 已归档

## 预期表现

文章管理中的内容状态应按以下顺序排列：

1. 草稿
2. 待发布
3. 已发布
4. 已归档

其中草稿应显示在文章列表的最上面。

## 影响

按该顺序展示后，用户可优先看到最需要处理的草稿，减少查找步骤。
