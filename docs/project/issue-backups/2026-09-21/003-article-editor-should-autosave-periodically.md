# 问题 003：文章编辑器应定期自动保存

- 记录时间：2026-09-21
- 来源：用户日常使用反馈
- 页面/区域：管理端文章编辑器
- 状态：已修复（2026-09-24）

## 用户原文

> 编辑文章时应当每隔一段时间就自动保存一次,以免在多设备上同时编辑文章,a设备未保存引起的同步问题

## 当前表现

文章编辑器没有每隔一段时间自动保存内容。用户在多台设备上编辑同一篇文章时，如果 A 设备
尚未保存，可能引发设备之间的内容同步问题。

## 预期表现

编辑文章时应按固定时间间隔自动保存，降低某台设备未保存就离开页面或多设备同时编辑时的
内容冲突和丢失风险。

## 影响

未保存内容可能与其他设备中的版本产生同步冲突，导致编辑结果不一致或丢失。
