# 问题 002：分类名称不应简写

- 记录时间：2026-09-21

## 用户原文

> 分类不应该简写文字：计算机基础就是计算机基础，不应该简写为计算机...

## 当前表现

分类选项名称被省略号截断，例如“计算机基础”显示为“计算机…”，“数据结构”显示为
“数据结…”，无法完整显示分类名称。

## 预期表现

分类名称应完整显示。例如“计算机基础”应显示为“计算机基础”，不应简写或截断为
“计算机…”。

## 影响

相似分类可能难以区分，用户不能在选项中可靠识别完整分类名称。
