# 会话摘要 - 公开在线编辑器

## 本次目标

1. 将 `/editor` 从占位页升级为纯浏览器 Markdown 编辑器。
2. 实现导入、下载、实时预览、本地草稿恢复和移动端编辑/预览切换。
3. 完成单元测试、构建、桌面与 390px 浏览器检查并同步文档。

## 当前阶段

- 后端核心 API、公开端业务页面、公开在线编辑器和管理端核心业务页均已实现。
- 在线编辑器不调用后端，草稿只保存在 `umo-editor-draft-v1`。
- 浏览器 E2E、视觉回归工程和 `robots.txt` 仍未实现。

## 关键决策

| 决策 | 结论 |
|---|---|
| 事实来源 | 当前代码优先于旧设计稿 |
| 编辑器实现 | 原生 textarea + `MarkdownArticle`，不引入 CodeMirror/Monaco |
| 后端边界 | 不做内容 API 调用，不增加数据库或接口 |
| 导入覆盖 | 当前内容非空时先确认替换 |
| 草稿存储 | `umo-editor-draft-v1` v1 JSON：content、fileName、updatedAt |
| 草稿恢复 | 300ms 防抖保存，路由离开/页面隐藏前刷新 |
| 下载 | UTF-8 Blob，文件名规范化为安全 `.md` |
