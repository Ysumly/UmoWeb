# 会话摘要 - Docker 全栈启动与部署基线

## 本次目标

1. 建立 MySQL 8.4、Spring Boot 和 Nginx 前端的 Docker Compose 全栈。
2. 自动生成凭据、导入演示数据并持久化数据库、Markdown 和上传图片。
3. 修正反向代理下的客户端 IP/CIDR 语义，并完成真实接口与大文件验证。

## 当前阶段

- Docker Desktop、Compose v5.5.0 和本机 Chrome 可用。
- Compose 栈已在 `http://localhost:18080` 完成本机验证并保留运行。
- 仓库默认入口仍为 `8080`，本地因端口冲突只在被忽略的 `.env.docker` 使用 `18080`。

## 关键决策

| 决策 | 结论 |
|---|---|
| 事实来源 | 当前代码和运行中的容器优先于旧设计稿 |
| 容器数据库 | MySQL 8.4，首次空卷导入 schema 与演示数据 |
| 入口 | Nginx 唯一宿主入口，后端和 MySQL 不暴露宿主端口 |
| 凭据 | `.env.docker` 自动生成并被忽略 |
| 代理限流 | Nginx 固定 `172.30.0.10`，`TRUSTED_PROXIES=172.30.0.10/32` 并覆盖 XFF |
| 数据 | `mysql_data` 和 `app_data` 命名卷 |
