# 会话摘要 - Playwright 浏览器 E2E 与视觉回归

## 本次目标

1. 为前端建立可重复执行的 Playwright functional 与视觉回归。
2. 覆盖公开端、在线编辑器、管理端核心流程及桌面/390px 布局。
3. 保持真实 MySQL 冒烟与浏览器 Mock API 测试的职责边界，并同步项目文档。

## 当前阶段

- 后端核心 API、公开端业务页面、在线编辑器和管理端核心业务页均已实现。
- Playwright 使用本机 Chrome、Vite preview 和状态化 Mock API，不依赖 MySQL。
- 14 张视觉基线已提交，视觉测试连续比较稳定。

## 关键决策

| 决策 | 结论 |
|---|---|
| 事实来源 | 当前代码优先于旧设计稿 |
| 浏览器数据 | `/api/**` 浏览器级 Mock，仅验证前端行为 |
| 真实后端 | 继续使用隔离 MySQL 与 `api-smoke.ps1` |
| 浏览器引擎 | 本机 Chrome channel，不安装 Playwright 独立浏览器 |
| 功能范围 | 16 个公开端、编辑器和管理端用例 |
| 视觉范围 | 7 个页面状态 × 桌面/390px，共 14 张基线 |
| CI | 本轮仅提供本地脚本，不添加 GitHub Actions |
