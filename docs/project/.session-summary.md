# 会话摘要 - 阿里云 ECS 公网测试部署

## 本次目标

1. 在单台阿里云 ECS 上部署 MySQL 8.4、Spring Boot 和 Nginx 前端。
2. 处理 ECS 外部仓库访问受限、无域名和安全组边界问题。
3. 验证公网首页、公开 API、管理员登录和容器开机恢复。
4. 将部署事实脱敏同步到仓库，不上传实例标识、地址或任何凭据。

- 正式内容、备份恢复和本地版本化发布已完成；当前运行 `v1.0.0-rc.5`，
  ECS 29/29、迁移、正文索引、四款游戏和访问安全验收通过。
- Task 3.1 管理端单文件 Markdown 导入、Task 3.2 分类子级筛选、Task 3.3 图片删除与
  引用保护、Task 3.4 正文全文搜索和 Task 3.5 四款训练游戏已全部合并 master，
  第三阶段出口条件已满足。
- Task 4.1 已完成文章目录、滚动章节高亮、阅读进度和最多 4 篇相关阅读；
  正文内检索由浏览器原生查找承担，不提供站内正文搜索控件。
- Task 4.2 的图片一致性检查已完成：管理端按需扫描断裂引用、数据库记录缺文件和磁盘孤立文件，
  显示来源与扫描时间；不自动修复，也不新增数据库表。

## 关键决策

| 决策 | 结论 |
|---|---|
| 网络入口 | 安全组与 UFW 只放行 TCP 80，MySQL 和后端不暴露 |
| 镜像交付 | ECS 外网受限时由开发机构建并经 SHA-256 校验后 `docker load` |
| 启动方式 | `compose up -d --no-build --wait`，不在 ECS 重新拉取基础镜像 |
| 凭据 | `.env.docker` 权限 600，只保存在 ECS，不进入版本库 |
| 公网状态 | 无域名 HTTP 测试部署，后续再接入 HTTPS |
