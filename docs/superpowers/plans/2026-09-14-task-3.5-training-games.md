# Task 3.5 四个训练游戏实施计划

> 状态：已完成并合并 master。

**Goal:** 将四份独立静态 HTML 游戏迁移为统一的 Vue 公开路由，保留原规则和旧版成绩存储。

**Architecture:** 游戏中心与四款游戏位于公开端 `PublicLayout`，共享页头和结果弹窗；
规则、随机逻辑和旧存储解析集中在纯 JavaScript 模块，游戏页面只负责计时、状态和渲染。

**Tech Stack:** Vue 3.5、Vue Router 5、Vite 8、Node test、Playwright 1.63。

## Global Constraints

- 不新增后端接口、Schema、账号同步、排行榜或运行时依赖。
- 保留 `stroop_84_parchment`、`poker_memory_best_span`、`schulte_parchment_best` 兼容性。
- 数字展示时长、扑克牌三秒记忆等规则计时不变；非必要动画和反馈等待缩短。
- 游戏路由不播放全屏擦除动画，进入页面立即可操作。
- 桌面、手机、短屏、横屏和高密度网格不能出现页面横向溢出。
