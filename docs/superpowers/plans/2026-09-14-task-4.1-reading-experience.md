# Task 4.1 阅读体验增强设计与实施记录

> 状态：已完成。目录、阅读进度、浏览器原生正文检索和确定性相关阅读均已收口。

**Goal:** 在公开文章详情中提供自动目录、滚动章节高亮、阅读进度和确定性相关阅读；
正文内检索由浏览器原生查找承担，不改变文章存储格式，也不新增接口。

**Architecture:** 使用与正文渲染相同的 marked token 流生成稳定标题 ID；公开详情在桌面端
将目录放入篇章信息侧栏，在窄屏使用悬浮目录面板。滚动状态由文章边界和标题位置直接计算。
相关文章由现有详情接口内联返回，使用分类、标签和类型加权排序，不使用 Pinia 或浏览器持久化。

**Tech Stack:** Vue 3.5、Vite 8、marked 18、Node test、Playwright 1.63。

## Global Constraints

- 不修改正文存储、数据库或管理端编辑合同。
- 相关文章扩展现有公开详情响应，不新增接口，也不改变管理端详情结构。
- 标题 ID 必须可重复生成；重复标题追加稳定序号，不覆盖已有 DOM ID。
- 原始 HTML 继续转义；只识别严格受限的旧版标题 `<span id="...">...</span>`。
- 目录只展示首个文档 H1 之后的 H1、H2、H3，并忽略名为“目录”的章节。
- 少于两个可导航标题时不显示目录和阅读进度。
- 移动端目录不能遮挡正文操作或造成页面横向溢出。

## 已实现

- [x] 从 Markdown 生成 H1-H3 树，忽略首个文档 H1、“目录”章节和代码块内容。
- [x] 为标题生成规范 ID、旧版兼容别名和重复标题序号，渲染与目录共用同一解析结果。
- [x] 保留安全旧版标题 span 的显式 ID，同时继续转义不安全 HTML。
- [x] 新增桌面目录、分支展开、当前章节和祖先高亮。
- [x] 新增窄屏悬浮目录、Escape/点击外部关闭和关闭后焦点恢复。
- [x] 新增文章阅读进度条、滚动/resize/内容尺寸监听和卸载清理。
- [x] 支持 URL hash 深链接与目录点击后的 hash 同步。
- [x] 新增已知旧文字锚点、大小写兼容锚点和显式标题 ID 的迁移脚本，支持 dry-run、
  Apply 前外部备份和原子写入。
- [x] 确认正文内检索由浏览器原生查找承担，不新增站内搜索控件或服务端依赖。
- [x] 公开详情内联最多 4 篇相关文章，按共享标签、分类和同类型排序，排除当前及前后篇。
- [x] 增加双冒烟断言、MySQL 8.4 集成测试和 Playwright 桌面/移动回归。
- [x] 更新现有 `post-detail` Windows/Linux 视觉基线，覆盖相关阅读状态。

## 未实施

- 正文格式迁移或全量 Markdown 重写；旧锚点脚本必须显式指定根目录和备份目录后运行。
