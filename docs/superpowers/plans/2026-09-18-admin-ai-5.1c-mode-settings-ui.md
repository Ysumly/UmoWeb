# 5.1C 管理端 AI 模式设置页 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development`
> (recommended) or `superpowers:executing-plans` to implement this plan task-by-task.
> Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** 在管理端增加独立“AI 设置”页面，让管理员无需修改代码即可新建、复制、编辑、启停、
排序、查看和回滚转换模式提示词。

**Architecture:** 页面只消费 5.1B 的六个模式目录接口。表单、校验、排序和载荷转换放入纯 JavaScript
工具模块，Vue 页面负责异步状态和交互。路由和侧栏增加独立入口，文章编辑器不在本计划修改。

**Tech Stack:** Vue 3.5、Vue Router 5、Axios 1.18、Vite 8、Node test、Playwright 1.63。

**Spec:** [管理端 AI 计划总索引](2026-09-18-admin-ai-index.md) 与
[5.1B 模式目录后端](2026-09-18-admin-ai-5.1b-mode-catalog-backend.md)

## Global Constraints

- 不新增前端依赖，不引入组件库、编辑器库或图标包。
- 页面只使用现有 Axios `client`、管理端布局、表单样式和 `ContentState`。
- `modeKey` 创建时必填、编辑时只读；系统提示词不可为空，最大 20,000 字符。
- 新建和复制模式默认停用；启用通过保存 `enabled=true` 完成。
- 提示词版本只显示最近 10 版；回滚前必须确认，回滚成功后刷新当前模式。
- 首版页面不提供永久删除按钮。
- 移动端不得出现横向溢出；表格区域允许横向滚动，编辑表单必须单列显示。
