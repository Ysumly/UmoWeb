# 5.1A 管理端 AI 产品与数据契约 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use `superpowers:subagent-driven-development`
> (recommended) or `superpowers:executing-plans` to implement this plan task-by-task.
> Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 冻结管理端 AI 的产品流程、隐私边界、可配置模式、版本策略、接口字段和测试口径，
让后续五个子计划只按冻结契约实现，不重新决定产品行为。

**Architecture:** 本计划只修改设计与状态文档。实现契约以总索引和本计划为唯一入口；运行时 Schema、
API 和页面分别在 5.1B–5.1E 交付，真实模型质量与发布由 5.1F 收口。

**Tech Stack:** Markdown、项目现有 `docs/design`、`docs/modules` 和 `docs/project` 文档结构。

**Spec:** [管理端 AI 计划总索引](2026-09-18-admin-ai-index.md)

## Global Constraints

- 当前代码是唯一事实来源；未实现能力必须标记为计划，不得写入“已实现”表格。
- 默认模式提示词只允许存在于数据库记录和幂等 SQL 数据，不进入 Java、Vue 或测试常量。
- 正文输入最多 20,000 字符，结果最多 60,000 字符，超时 180 秒，10 分钟最多 5 次，
  同时最多一个请求，不实现费用硬上限。
- 草稿使用 `sessionStorage["umo-admin-ai-source-v1"]`，结果使用
  `localStorage["umo-admin-ai-result-v1"]`，两者都不进入数据库或服务器备份。
- AI 结果只能编辑和复制，不得自动插入、替换、保存或发布文章。
- 最近保留 10 个提示词版本，回滚必须生成新版本而不是改写旧版本。
- 真实供应商只在 5.1F 的受控人工验收中调用，CI 使用假供应商。
