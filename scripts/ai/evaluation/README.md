# AI 模式固定质量样本

本目录保存管理端 AI 五种模式的 10 个固定、公开、安全的人工评测样本。
`cases.json` 的顶层为 `cases` 数组，每项包含唯一 `id`、`modeKey`、`source`
和 `criteria`。所有样本均为仓库内合成的短文本，不包含个人隐私、真实服务器地址、
密钥或未授权的第三方长文。

## 人工评分口径

```text
5：完全满足模式要求，无事实问题
4：有轻微风格或措辞问题，事实和结构完整
3：可理解但存在明显遗漏、语气偏差或结构变化
2：关键信息丢失或表达不可用
1：完全失败、空结果或违反模式边界
```

## 模式门槛

- `STRUCTURE_CLEANUP` 必须通过自动和非标题正文 100% 一致检查。
- 其他模式每个样本至少 4 分。
- 翻译样本的数字、专有名词、链接和代码必须无误。
- `LIGHT_NOVELIZATION` 输出不得超出原文 1.5 倍。

## 校验命令

在仓库根目录运行：

```powershell
python -m unittest scripts.ai.evaluation.test_cases
```
